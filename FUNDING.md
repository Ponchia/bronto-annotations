# Support Bronto Annotations

Bronto Annotations is maintained by [Zeno Trevisan / Ponchia](https://brontolotto.observer/).
You can support this work through [Ko-fi](https://ko-fi.com/ponchia).

Support helps make room for maintenance, bug fixes, documentation, and testing
across the chart and diagram libraries used by the project. This is the
maintainer's existing Ko-fi page, not a separate project fund.

Funding is optional. The package is available under the [MIT license](LICENSE);
using it, reporting a bug, and contributing do not require a payment. A tip
does not purchase a feature, a delivery date, or a support agreement.

Useful non-financial contributions include a minimal bug reproduction, a clear
account of integration friction, improved examples, or sharing a project that
uses the library. Read [CONTRIBUTING.md](CONTRIBUTING.md) to get started.

For technical help, use [SUPPORT.md](SUPPORT.md). Keep security reports on the
private reporting path described in [SECURITY.md](SECURITY.md).
