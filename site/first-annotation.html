Make it yours

Save this HTML file and edit the annotation object in its module script. Open it in a browser with an internet connection: the package and stylesheet load from a version-pinned CDN. No repository clone, framework or API key is needed.

For an existing application, install the same release:

npm install @ponchia/annotations@0.9.2

Your application owns the chart, the input field and the saved note state. The package handles the annotation geometry and SVG. Continue with the complete application guide or choose an adapter for your existing surface.
